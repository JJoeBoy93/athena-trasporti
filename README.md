# athena-trasporti

Il sito di Athena Trasporti di Ardito Jacopo Joe. I fatti: [DATI.md](DATI.md).
Pubblicato con GitHub Pages dal ramo `main`.

Una sola pagina, senza framework né compilazione:

- `index.html` — la pagina
- `css/stile.css`, `js/sito.js` — stile, furgone sulla strada, modulo del preventivo
- `font/` — Playfair Display (licenza SIL OFL, in `font/OFL.txt`), servito dal sito stesso
- `img/` — immagini originali più versioni WebP leggere
- `controlli/` — `verifica.py`, da lanciare prima di ogni pull request (vedi `controlli/LEGGIMI.md`)
